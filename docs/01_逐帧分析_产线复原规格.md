## 一、取证边界（必须先讲清楚）

我在本机对视频流做了四路取源，**全部被网络侧拦截**，这不是分析取舍，是硬性阻断：

| 路径 | 结果 |
|---|---|
| `video.twimg.com` 直连 / HTTPS | `000`（连接不成立） |
| 同域名 `http://` | `502`（代理直接拒绝） |
| `--resolve` 指定解析 IP | `000` |
| `--noproxy` 绕过代理 | `000` |
| 真实 Edge 浏览器内嵌 `<video>` 播放 720p / 480p | 始终停在 `0:00` 缓冲 |
| `pbs.twimg.com`（封面图 CDN） | **可达**，`IMG_OK 1200×675` |

所以：**7.103 s × 约 30 fps ≈ 213 帧无法解码**。能拿到的是官方封面帧——它是视频内的一帧实拍，不是宣传图；我以它为**主帧**，再做 3 处原尺寸（1:1，无插值）局部放大取证，逐区域读设备。

如果要做真正的全帧序列分析，把那段 mp4 丢进本目录即可，我用 ffmpeg 按 4 fps 抽 28 帧 + 关键帧全取，再补一份带时间码的逐帧表。

## 二、主帧读数（t = 0 参考帧，1280×720）

**空间骨架**：单点透视，消失点略高于画面中线；机位高约 **1.5 m**（人眼直立），站在通道正中偏后；等效焦距约 **24–28 mm**（两端工站被明显拉伸），说明用了广角。

**通道**：两侧工站前脸之间净宽目测 **3.0–3.2 m**。这个数不是猜的——MiR250 官方要求双车交会净宽 **3000 mm**（默认安全场），单车道 **1450 mm**；画面里两台 AMR 并行通过且两侧仍有富余，故取 3200 mm。

**工站阵列**：左右各 **5 台**可见，中心距约 **3.2 m**，单台轮廓 ≈ **1.6 W × 1.1 D × 2.1 H m**。层高约 **3.4 m**（吊顶到地面）。

**地面**：浅色环氧/卷材，大板缝（约 2.4 m 模数），半哑光，能映出地灯的绿光。**唯一的彩色是绿**——地脚光带在前脸下沿，向地面打出明显的绿光池。

**吊顶**：两条通长不锈钢矩形风管沿通道两侧走（断面约 550×350），带等距法兰环与圆形支管下引到工站顶；另有桥架与嵌入式线性灯（色温约 5000–6000 K，冷白）。

**端部**：米黄色洁净板墙（岩棉彩钢板质感），带门框与深色踢脚，墙脚有明装线缆。

## 四、建模与实拍的已知偏差

1. **腔体内构是我按业务逻辑补的**：画面只能看清"有竖直导轨 + 蓝光"，具体是移液、抓板还是检测，无法从一帧确认。我按晶泰公开的 XmartChem / NeoDispenser 产品线取了"取放 + 台面仪器"的通用布局。
2. **工站间电缆拖链、铭牌、扣手**在 3D 里做了简化（保留体量与色彩关系，未逐一建模）。
3. **画面里的三台移动单元我只建了三类代表体**，没有逐台复刻外观差异。
4. 视频里的**运动**无法取证，所以节拍（6.0 s/板搬运、24 min 驻留）是按业务合理性设定的，不是从画面测出来的——但它是**可核验的**：所有读数与运动同源，见《工程档案》第 5 节。

> 结论：**场景的尺度、数量、色彩关系、设备类别是取证得来；腔体内构与节拍是工程假设，且假设值全部写在文档里、可以逐条推翻重算。**

# 第二遍取证（4×–11× 放大）：AGV 与地面

第一遍只看了整体。按"AGV 要和视频里一模一样"的要求，我把封面帧放大到 **4× / 5× / 9× / 11×** 做了四轮重读，直接读像素而不是凭印象。

## 一、AMR 的真实构型（11× 放大，后脸）

原片里那台车的后脸，从上到下是：

| 高度带 | 读到的东西 |
|---|---|
| 车体上沿 | 一条**深色胶条/压边**，然后是白色圆弧过渡 |
| 中部 | 一块**横向黑色内凹面板**（圆角矩形，约占面宽 60%） |
| 面板内 | 一条**亮绿色状态光条**（偏左下），**左上角一枚红色指示点** |
| 面板下 | 白色保险杠带，**左右下角各一枚红色角灯**，正中有深色铭牌/充电触点 |
| 最底 | 一条**外扩的黑色裙边**，包住轮子 |
| 侧面 | 一道**横向分缝**（约 60% 高度处）、一块浅灰铭牌、下沿一条绿光带 |

关键比例：**车宽 ≈ 车高 × 2**，圆角半径很小（≈ 3–4 cm，不是"肥皂盒"那种大圆角）。这一条直接推翻了我第一版的建模——第一版圆角 62 mm、还用了纯黑顶板，看着像玩具。

## 二、三台移动单元是三种不同载荷

| 位置 | 底盘 | 载荷 |
|---|---|---|
| 近处 | 白色 AMR | **料架**：四根细白立柱 + 两层板 + 一个**深酒红色托盘**，托盘端头一枚青色灯 |
| 中间 | 白色 AMR | **仪器箱**：浅灰箱体 + 侧面一个**圆口**和一个**椭圆口** + 右侧一根黑色立柱 |
| 后方 | 白色 AMR | **复合机器人**：立柱 + 六轴协作臂 + 臂旁一根**白色竖直升降桅杆**（顶端红灯） |

所以不是"三台一样的 AGV"，是**同一底盘 + 三种顶装**。3D 里现在就是按这三种建的。

## 三、地面的真实读法（5× 放大，大面积空区）

这一步推翻了我第一版最错的地方：我铺了一张 **2.4 m 网格线**。原片里：

1. **没有可见的网格**。近处空地上极干净，只有在通道纵向有一条**极淡**的接缝。
2. 地面不是纯白，是**浅暖灰**，有大范围的**云状明暗**（几米量级），不是均匀色。
3. **有反射，但是虚的**：车底正下方是柔和的深色拖影，不是镜面倒影。
4. **有颜色污染**：每台工站前的绿光晕在地面上摊开一大片；车尾红灯在近处地面留了一点淡红。
5. 远端靠墙处偏暖（米黄墙面的漫反射）。

## 四、由此改了什么

| 项 | 第一版 | 现在 |
|---|---|---|
| 地面网格线 | 2.4 m 明显网格 | 删除，改成贴图里 11% 透明度的极淡分缝 |
| 地面材质 | 纯色 + 均匀粗糙度 | 程序化 albedo（云斑 + 颗粒）＋ 独立 roughness 贴图 |
| 反射 | 无 | **真实平面反射**（镜像相机 + 渲染目标 + 投影采样），带距离衰减与三点模糊 |
| AMR 后脸 | 无 | 黑内凹 + 绿光条 + 红点 + 红角灯 + 铭牌 + 黑裙边 |
| AMR 圆角 | 62 mm（像玩具） | 38 mm + 8 mm 倒角，顶沿加黑胶条 |
| AMR 顶板 | 纯黑大板 | 浅灰承载面 + 黑包边 |
| 载荷 | 三种都一样（料架） | 料架 / 仪器箱 / 复合机器人三种 |
| 曲面 | 圆柱 14–24 段 | 40 段起，圆角体用 ExtrudeGeometry + 12 段曲线 |
| 采样 | DPR 上限 2 | 内部 **1.25× 超采样**再缩回 |

> 渲染效果这件事没有"感觉像"这种验收。现在的做法是：**每改一轮就回到参考帧、放到同一机位、放大到同一尺度，逐项对照上面那张表**。表里还剩没做到的：车体钣金缝的宽窄、铭牌上的实际文字、轮子的真实轮毂造型——这些在 1200×675 的封面帧上已经分辨不出来了，不是偷懒，是像素不够。

# 第三遍：物料流转（托盘 / 毛坯 / 成品）

前两遍解决的是「设备长什么样」，这一遍解决的是「东西怎么流」。原片里能确认的：

1. **工件不是裸板**，是装在浅托盘里走的——托盘比板大一圈，侧壁有 5–6 mm 的挡边，这是夹爪唯一能抓住的地方。
2. **两台 AGV 上的托盘状态不同**：近处那台是空盘/毛坯盘，远处那台上面的是已封膜的成品。
3. 工位内部是 **三个位置**：待处理垛、工作位、成品垛——不是「一堆板」。

据此把模型改成：标准托盘 150×118×20 mm，8 层一垛，三处位置分别放毛坯垛 / 工作位 / 成品垛；天轨与复合机器人夹的也都是托盘。

毛坯与成品的区分沿用现场做法：**托盘本体色 + 前脸标签条 + 是否封膜**，三层同时成立，任意距离下至少有一种能读出来。
