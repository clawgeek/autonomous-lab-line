## 3. 结构核算

### 3.1 型材截面（按 2 mm 壁厚空心矩形数值积分，不查表）

40×80×2.0，6063-T5，E = 70 GPa：

- 面积 `A = 40×80 − 36×76 = 464 mm²`
- 惯性矩 `Ix = (40×80³ − 36×76³)/12 = 3.897×10⁵ mm⁴` → 面板显示 **39.0 ×10⁴ mm⁴**
- 抗弯截面系数 `Sx = Ix/40 = 9.74×10³ mm³`
- 回转半径 `r = √(Ix/A) = 29.0 mm`

### 3.2 台面横梁（跨 1.2 m，载 42 kg）

简支中点集中载荷 `P = 42 × 9.80665 = 411.9 N`：

| 量 | 公式 | 结果 |
|---|---|---|
| 跨中挠度 | `δ = PL³/(48EI)` | **0.544 mm** |
| 挠度限值 | `L/500` | 2.40 mm |
| 弯曲正应力 | `σ = M/S`，`M = PL/4 = 123.6 N·m` | **12.7 MPa** |
| 屈服 | 6063-T5 `fy = 205 MPa` | 安全系数 **16.1** |
| 弯曲刚度 | `k = 48EI/L³` | 758 kN/m |
| 一阶固有频率 | `f₁ = (1/2π)√(k/m)`，`m = 42+26 kg` | **16.8 Hz** |

**两个结论，一大一小：**

1. 强度安全系数 16，**这块梁不是强度控制，是刚度控制**——所以真正要盯的是 0.544 mm 挠度和 16.8 Hz。
2. 16.8 Hz 偏低。精密移液台面通常要求一阶频率 **> 25 Hz**（远离地面振动与行走激励的主频段 1–15 Hz）。16.8 Hz 已经贴着下边界，行走激励和泵组振动都可能被放大。**真实设计该做的不是加厚型材，而是把跨距从 1.2 m 缩到 0.9 m（f₁ 提升约 2.4 倍）或加中间支撑。** 面板上这一行我用警示色标了出来，没有让它看起来"很健康"。

### 3.3 机械臂基座螺栓

M8 8.8 级，4 颗，PCD ⌀172 mm。

- 应力截面积 `As = π/4 × ((d₂+d₃)/2)² = 34.1 mm²`
- 预紧力 `F₀ = 0.7 × σy × As = 0.7 × 640 × 34.1 = 15.3 kN`
- 最不利倾覆力矩（满载 7 kg 伸到满臂展 + 臂自重 26 kg 在 0.34 m 重心）：`M = 63.4 + 86.7 = 150.1 N·m`
- 单颗螺栓附加拉力（PCD ⌀190，2 颗受拉）：`F = M/(2×0.095) = 0.79 kN`

**0.79 kN 对 15.3 kN 预紧，只占 5.2%** —— 螺栓永远不会被拉开，真正会失效的是**预紧力松弛**（振动下螺纹副退扣）。所以工程上这一步的验收项是扭矩（M8 8.8 约 25 N·m）与防松胶，不是强度校核。

### 3.4 抗倾覆

`K = (b/2) / (h_cg · a / g)`

| 对象 | b | h_cg | a | K |
|---|---|---|---|---|
| 工站（含脚轮） | 1.60 m | 1.05 m | 0.60 m/s² | **12.5** |
| 复合机器人（带料架） | 0.58 m | 0.62 m | 0.60 m/s² | **7.6** |

按 ISO 3691-4 的思路，K > 2 即安全；7.6 说明**复合机器人真正的风险不是倾覆，而是高速转弯时料架上的微孔板滑移**——所以实际做法是限速 + 料架加挡边，而不是加重底盘。

## 4. 运动学

### 4.1 七轴 IK（S-R-S 构型，末端强制竖直向下）

七轴臂的关节定义：**J1 基座回转 → J2 肩俯仰 → J3 上臂滚转（冗余）→ J4 肘俯仰 → J5 前臂滚转 → J6 腕俯仰 → J7 法兰回转**。

抓放微孔板要求**工具轴始终竖直向下**，所以不能用"直腕"近似。做法：

1. 工具点 `T` 竖直向下 ⇒ 法兰中心在 `W = T + (0, L3, 0)`（L3 = 63 mm）。
2. `J1 = atan2(dx, dz)`，`r = √(dx²+dz²)`。
3. 平面二连杆（**只用 L1=450 与 L2=410**，不含 L3）：
   ```
   θ4 = −acos((d² − L1² − L2²)/(2·L1·L2))      // 肘上解
   θ2 = atan2(y, r) − atan2(L2·sinθ4, L1 + L2·cosθ4)
   ```
4. **J6 补偿**：前臂方向角 `φ = θ2 + θ4`，令 `J6 = π/2 + φ`，使工具轴 = `θ2+θ4−J6 = −π/2`（竖直向下）。
5. **J7 补偿**：`J7 = −J1`。J1 偏航后夹爪的指缝会跟着转，`J7 = −J1` 把它转回来，保证指缝始终与板边平行。实测 `J1 + J7 = 0.0°`。

**冗余轴 J3/J5**：S-R-S 的零空间自由度。这里让 `J3 = 0.34·sin(2π·phase)`、`J5 = −J3`（成对抵消，不改变末端位姿），视觉上就是上臂与关节模组在"转肘"——这是七轴臂最标志性的动作，六轴做不到。

**闭环校验**：工具点由 FK 反推，与目标点最大偏差 **0.00 mm**。

**臂展自洽**：`L1 + L2 + L3 = 450 + 410 + 63 = 923 mm`，Diana 7 官方 923 mm，**完全对上**。

**臂展利用率**：工位臂 60–70%，复合机器人 69%。均未贴满。

**末端负载率**：板 0.92 kg + 夹爪 1.2 kg = 2.12 kg / **7.0 kg = 30%**。

**为什么不用 6 轴**：6 轴在"工具竖直向下"约束下少了腕部自由度，末端姿态要沿前臂方向妥协，夹爪会斜着咬板；7 轴的冗余滚转正好把这个姿态自由度补回来，同时能在不动机器人基座的前提下让肘部避开腔体内的仪器。

### 4.2 AMR 梯形速度曲线

`v = 1.20 m/s`，`a = 0.50 m/s²`，安全回路响应 `t_react = 0.10 s`：

```
制动距离 = v·t_react + v²/(2·a_brake)
        = 1.20×0.10 + 1.20²/(2×0.60)
        = 0.12 + 1.20 = 1.32 m
```

**这个数要对着 MiR250 的安全场看**：官方单车道净宽 1450 mm，我的制动距离 1.32 m —— 1.32 < 1.45，**保护区刚好兜得住**。面板上那根横条就是 `1.32 / 1.45`。如果谁把限速提到 1.6 m/s，制动距离变 2.29 m，横条立刻变红——**这是这套参数里唯一会真正"报警"的地方，不是装饰。**

## 7. 已知简化（别当成实物图纸用）

1. 几何是**体块级复原**：钣金折弯、筋位、焊缝、线束走向都没建。
2. 力学是**一维梁模型**：没做有限元，模态只算了一阶，没考虑柜体蒙皮的局部模态与脚轮非线性。
3. 节拍是**工程假设**，不是实测。要改成实测值，只改 `model.js` 顶部 `SPEC.cycle` 与 `LINE` 的驻留参数，页面上所有数字、所有动作会同步跟着变——这正是"一个输入驱动全部"的意义。
4. 没有算热与气流（风管只做了体量），没有算洁净度分区。


## 8. 渲染实现（为什么它看起来像现场）

这一节不是美术说明，是**可复算的技术指标**，因为"真实感"如果不可度量就只是形容词。

### 8.1 地面：程序化纹理，不下载贴图

单文件离线，不能依赖任何贴图文件。地面贴图是运行时用 Canvas 2D 生成的 1024×1024：

- **反照率**：基色 `#E9E7E1`，叠加 300 个半径 40–240 px 的径向渐变斑（明暗各半，α 0.010–0.030）→ 大尺度云斑；再逐像素加 ±3 级噪声 → 细颗粒；最后在贴图边缘描 11% 透明度的分缝线，靠 RepeatWrapping 得到 3.2 m 模数的极淡接缝。
- **粗糙度**：另一张 512×512，基线 `#828282`（≈0.51，哑光），150 个斑块在 0.38–0.65 之间摆动 → 高光会碎，不是一整片镜面。
- 两张图 `anisotropy = 8`，掠射角不糊。

### 8.2 反射：真平面反射，不是假贴图

每帧额外渲染一遍镜像场景到 880×495 的 `WebGLRenderTarget`：

1. 把相机位置对 y=0 镜像：`p' = (x, −y, z)`；方向与 up 同时镜像；`lookAt` 到镜像目标点（这是 three.js `Reflector` 同一套数学，得到的是合法右手相机，法线剔除不会翻）。
2. `textureMatrix = bias · P · V⁻¹`，把世界坐标直接投到反射图的 [0,1] UV。
3. 用 `onBeforeCompile` 注入到地面的 `MeshStandardMaterial` 里——**保留 PBR 与阴影**，只在 `gl_FragColor` 上叠反射：

```glsl
vec2 ruv = vReflUv.xy / vReflUv.w;
float fade = 1.0 - smoothstep(3.0, 17.0, vReflUv.w);   // 远处不反
vec3 rc = texture2D(tRefl, ruv).rgb * 0.46
        + texture2D(tRefl, ruv + vec2(0.0, 0.010)).rgb * 0.30
        + texture2D(tRefl, ruv - vec2(0.0, 0.014)).rgb * 0.24;  // 三点竖向模糊
gl_FragColor.rgb = mix(gl_FragColor.rgb, rc, reflStr * fade);   // reflStr = 0.15
```

三点采样是有道理的：真实环氧地坪不是镜面，反射被**竖向拉长并模糊**，这个偏移量对应约 1–2 cm 的表面不平度。

### 8.3 曲面质量

| 对象 | 处理 |
|---|---|
| AMR 车体 | `ExtrudeGeometry` + 圆角矩形轮廓，`curveSegments 12`、`bevelSegments 3`，倒角 8 mm |
| 圆柱件（关节、脚轮、传感器） | 径向 40 段起（原来是 14–24） |
| 整体采样 | 内部 `devicePixelRatio × 1.25`（上限 2）渲染再缩回，等效 1.25× 超采样 |

### 8.4 性能代价（必须说）

多出来的一次全场景渲染，在 880×495 上是主画面的约 **30% 像素量**。如果开了 1.25× 超采样，1080p 屏上填充率大约翻 2.3 倍。**在集显机器上可能掉到 30 fps**——这不是理论风险，是这套做法的固有代价。要保帧率，优先砍反射分辨率（880→640）而不是砍超采样，因为反射模糊了看不出来，锯齿看得出来。

## 10. 取件动作（不是摆设，是算出来的）

### 10.1 工位臂：A 栈 → 工作位

航点全部是**笛卡尔点**，关节角由 IK 反解，不是手 K 的关键帧：

```
上方A(−0.52, 1.185, 0.05) → 下探(−0.52, 1.060) → 提起 → 横移
→ 下放B(0, 0.952) → 抬起 → 回A上方
```

- 偏航由 `yaw = atan2(dx, dz)` 得到，A 栈时 −61°、工作位时 0°，中间连续摆动。
- 实测算下来臂展利用率 **60%–70%**，没有一次贴满臂展。
- 夹住的板是一块独立网格，在 carry 相位可见并跟着工具点走；料垛 A 每循环少一片、成品 C 每循环多一片。

### 10.2 复合机器人：接料台 → 本车台面

- 六个航点：台面上方 → 下探夹板（y=0.985，台面顶 0.953，留 3 cm）→ 提起 → 收回 → 放到台面（y=0.340）→ 抬起。
- 臂展利用率 **55%–69%**。
- 板件三态：`onShelf`（在工位接料台上）/ `carry`（夹爪里）/ `onDeck`（本车台面），任何时刻只有一个为真，不会出现"两块板"。

### 10.3 上下料 AGV：由天轨卸料

料架 AGV 在 `x=9.40, z=−0.75` 停靠 **30.2 s**（正好覆盖天轨两次下探窗口 8.0 s 与 37.0 s），天轨把顶层板垛的板取走、再把成品放回。料架上的 6 片板随取料次数增减。

## 11. 天轨机器人（工位加工部送料）

### 11.1 结构

龙门式三轴：两条纵轨（z=±2.36，y=2.72，吊架每 2.9 m）＋ 横梁（y=2.62，跨 4.72 m）＋ 沿梁小车（Y 向）＋ 升降立柱（Z 向）＋ 二指夹爪。

**为什么横梁压到 2.62**：顶上两条风管底面在 2.81，横梁若按常规放在 2.8–3.0 会直接穿管。把整套降到风管以下，是这套布局里唯一的解——不是审美选择。

### 11.2 时序（48 s 一个循环）

| 时间 | 动作 |
|---|---|
| 0–4 | 从停放位 x=3.0 驶向取料位 x=9.40 |
| 4–8 | 横移到 AGV 车道（z=−0.75）上方 |
| 8–10.5 | 下探到 y=0.80 夹取板垛顶层 |
| 10.5–15.5 | 提升到 2.46，驶向工位 x=11.0 |

## 12. 安全与监控层

### 12.1 防干涉：两个真实会撞的地方

**① 天轨 ↔ 工位臂**（最危险）
天轨夹爪要下探到 y=1.26 从顶部投料口送料，而工位臂的作业面在 y=0.95–1.20、z=0.05 —— 两者的空间是重叠的。原来两者各动各的，必然撞。

加**让位联锁**：实时算天轨与最近工位的距离 `bd` 与高度 `ys`：
```
prox = clamp((1.35 − bd) / 0.45)      // 水平接近度
low  = clamp((2.38 − ys) / 0.50)      // 垂直下探度
zoneAmt = prox × low
```
`zoneAmt` 从 0 到 1 时，该工位臂的工具点从当前作业点**线性插值到停靠位 (0.60, 1.10, −0.26)**，然后重新解 IK —— 所以是平滑让位，不是瞬移。

实测让位后**臂—天轨最小间隙 0.82 m**（原来物理重叠）。HUD 实时显示这个数，低于 0.5 m 变警告色。

**② 滑窗 ↔ 工位臂**
下片窗下潜时若臂还在窗口区，会切到臂。加联锁：`pose.z > 0.24` 时窗口**禁止关闭**（强制 open ≥ 0.6）。

**③ 天轨作业时强制关窗**
`zoneAmt > 0.45` 时该工位窗口强制关闭——不是防机器人，是**防人**：天轨在头顶动的时候不能让人把手伸进去。

### 12.2 上下开窗

前脸改成上下双开滑窗：

| 件 | 范围 | 动作 |
|---|---|---|
| 上片 | y 1.32 → 1.945 | 上升 **0.12** |
| 下片 | y 0.95 → 1.32 | 下降 **0.38**，同时后退 0.045 藏进柜体（避免与柜门叠面） |
| 开窗后开口 | 0.94 → 1.44（0.50 高） | 正好在接料台高度，够板进出 |

## 13. 工件载具：托盘、毛坯/成品、料区

### 13.1 先修一个真 bug：夹爪指片在 TCP 上方 135 mm

截图里「夹爪空着、工件掉在下面」不是渲染问题，是几何方向反了。

七轴臂的链是往 +Y 生长，工具轴被 `J6 = π/2 + φ` 强制指向 **−Y**。所以法兰（J7 原点）在 TCP **上方** L3 = 63 mm。第一版把指片建在 `+0.072`，也就是法兰上方——指片实际位置 = TCP + 63 + 72 = **TCP 上方 135 mm**，而工件按 TCP 摆放。差 135 mm，正好是截图里那道缝。

改法：指片移到 `−0.055`，指面中心落在 TCP，指片高度收到 36 mm，覆盖「托盘底 → 托盘顶上方 6 mm」。这样夹着托盘往下放料时，指片不会插进托架导轨。

| 项 | 改前 | 改后 |
|---|---|---|
| 指片中心（J7 局部 y） | +0.072 | **−0.055** |
| 相对 TCP | 上方 135 mm | **0（夹持中心 = TCP）** |
| 指片高度 | 58 mm | 36 mm |
| 指间距（闭合） | 124 mm | **150 mm**（对应托盘外宽） |
| 天轨指片 | 90 mm 长、跨 136 mm | 46 mm 长、跨 160 mm |

### 13.2 标准托盘（工件不再裸着流转）

| 项 | 值 | 说明 |
|---|---|---|
| 外廓 | **150 × 118 × 20 mm** | X 向 150 是被夹持方向 |
| 盘底 / 侧壁 | 6 mm / 14 mm（壁厚 5） | 侧壁外表面正好落在指面 |
| 内腔工件 | 127 × 85 × 14 mm | 标准 SBS 微孔板尺寸 |
| 定位垫 | 1.5 mm 硅胶 | 防止板在托盘内窜动 |
| 垛叠层距 | 22 mm | 托盘 20 + 2 mm 嵌套余量 |
| 单垛层数 | 8 | 垛高 176 mm |
| 夹持高度 | 托盘底面 + 10 mm | 指片夹的是侧壁中段 |

改前是「裸板直接垒 8 层」，改后是「8 个托盘」。**所有搬运对象（工位臂、天轨、复合机器人）夹的都是托盘，不是板**——这是真实产线的做法，因为裸板没法定位、也没法被夹爪可靠夹住。

### 13.3 毛坯 / 成品怎么区分

不是靠贴个标签糊弄，三层信息同时给：

| | 毛坯 RAW | 成品 FIN |
|---|---|---|
| 托盘本体 | 冷蓝灰 `#C6D2DE` | 冷绿灰 `#C6D6CB` |
| 前脸标签条 | 蓝 `#2E6BE6`，52 × 9 mm | 绿 `#1EAE6E`，同尺寸 |
| 工件 | 冷白微孔板 `#E9EEF3`，哑光 | 琥珀底 + **银箔封膜**（金属度 0.78） |

封膜是成品最真实的特征——微孔板做完实验要封膜才能流转，视觉上一眼就能和空白板分开。

### 13.4 取放时序（首尾闭合，不是拼接动画）

一个循环 6.0 s（CT = 48 s ÷ 8 层），14 个位置关键帧：

| 相位 | 动作 |
|---|---|
| 0.00 | 在 C 成品垛刚放下，空爪 |
| 0.10 → 0.22 | 抬到跨越高度，驶向 A 毛坯垛 |
| 0.28 → 0.32 | 下探到 A 垛顶层面，**夹住毛坯托盘** |
| 0.42 → 0.54 | 提升、横移到 B 工作位上方 |
| 0.62 → 0.66 | 下放到工作位，**放开** |
| 0.66 → 0.78 | 加工停顿（托盘在工作位上，毛坯态） |
| 0.78 | **夹住成品**（同位置，工件已封膜） |
| 0.86 → 1.00 | 提升、横移到 C，放到成品垛顶 |

**为什么这样排**：单臂单工位，物理上必须「先把成品取走，才能放新的毛坯」。上一版是「A→B 放毛坯，再 B→C」，那样 B 位在 85% 的时间里是空的，而且放下毛坯后立刻又当成品夹走——逻辑上讲不通。现在改成「C→A→B→C」的闭环，帧与帧之间最大位移 64.8 mm（≈2.1 m/s，低于 TCP 上限 2.4 m/s），没有跳帧。

托盘在「夹爪里 / 垛上 / 工作位」三种状态互斥，任何时刻只有一个可见，不会出现两块托盘。

### 13.5 车间料区

在线体东端（围栏外，x 16.9–20.5），各 **3.6 × 2.6 m**：

| | 毛坯料区 RAW | 成品料区 FG |
|---|---|---|
| 地面涂装 | 蓝色块 + 双线边框 + 四角斜纹 | 绿色，同构造 |
| 地面文字 | 「毛坯料区 / RAW MATERIAL」 | 「成品料区 / FINISHED GOODS」 |
| 立牌 | 1.44 × 0.51 m 双面，深底 + 色条 | 同规格，绿色 |
| 料架 | 1.46 m 高 × 3 层 × 12 托盘 = **36 盘** | 同规格 |
| 地面托盘垛 | 2 垛 × 4 盘/层 × 3 层 = **24 盘** | 同规格 |
| 边界柱 | 4 根，0.62 m，顶灯同色 | 同规格 |

料架用双导轨代替整块层板——整块层板会从斜下方把托盘完全挡住，双轨能让 12 个托盘都露在外面，远看能数清。

地面文字沿 **Z 轴**排版（不是 X）：人从产线一侧往东看时，文字是横的，符合现场标识的读法。
