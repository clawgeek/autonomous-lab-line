# 自主实验室产线 · 数字样机拆解

**Autonomous Lab Production Line — Digital Teardown**

一条十工位自主实验室产线的可交互数字样机：3D 场景、结构力学读数、物料流转时序全部由**同一个参数集**驱动。改一个数字，画面和读数一起变。

视频 4:04 · 1080p24 · 温柔女声配音 · 中英双语字幕 · AI 封面开场。

---

## 一、这个项目在做什么

不是"把设备画出来"，而是**让它可以被复算和被质疑**。

| 维度 | 做法 |
|---|---|
| 几何 | 尺寸追到真实型号：MiR250（0.80×0.58 m）、Diana 7 七轴臂（923 mm 臂展）、6063-T5 铝型材 |
| 运动 | 工位臂 / 天轨 / 复合机器人三套机构，共用一个时间轴 `t`；无手拉关键帧 |
| 物料 | 工件装 150×118 mm 标准托盘流转；毛坯（蓝标）与成品（绿标 + 银封膜）全程可辨 |
| 结构 | 台面横梁跨中挠度、一阶固有频率、螺栓预拉力、抗倾覆系数，全部实算 |
| 安全 | 天轨与工位臂让位联锁、上下滑窗互锁、围栏 / 光幕 / 四路监控 |
| 料区 | 线体东端毛坯 / 成品两个料区，地面涂装 + 立牌 + 料架 + 托盘垛 |

## 三、几个能对上的数

| 项 | 值 | 校验方式 |
|---|---|---|
| 臂长自洽 | 450 + 410 + 63 = **923 mm** | Diana 7 官方 923 mm，完全一致 |
| 台面横梁 δ | **0.54 mm** | 简支中点集中载荷 `PL³/48EI` |
| 一阶固有频率 | **16.8 Hz** | 低于精密台面 25 Hz 门槛，面板标警示色 |
| 基座螺栓拉力 | 0.79 kN / 15.3 kN 预紧 | 占 5.2%，风险在松弛不在强度 |
| 通道宽度 | **3.2 m** | MiR250 双车交会需 3000 mm |
| 节拍 | 6.0 s/托盘 | 48 s ÷ 8 层 |
| 取放帧间位移 | 64.8 mm / 帧 | ≈2.1 m/s，低于 TCP 上限 2.4 m/s |
| 臂展利用率 | 60–62% | 从未贴满臂展 |

## 四、视频是怎么做的

不依赖浏览器帧率，也不录屏：

1. **文案**：57 句，按镜头分组，每句独立合成（句末必须是完整句号，否则语气悬空）。
2. **配音**：StepAudio 2.5 TTS，`wenrounvsheng` 音色；逐句按相对峰值阈值去掉首尾静音后拼轨，得到精确时间轴（TTS 自带 0.2–0.3 s 前导静音，不剪会让字幕抢跑）。
3. **渲染**：页面暴露 `window.__vid.step(dt)`，由外部按 1/24 s 步进 + 截图，得到 **5,792 帧确定性 24fps 序列**。这台机器实时录制只有 18–21 fps，直接录会抖。
4. **字幕**：时间码直接来自每句音频的真实时长，不按字数估算。
5. **封面**：AI 生成主视觉，再用系统字体程序化排版标题（AI 画字会糊），作为第一帧。
